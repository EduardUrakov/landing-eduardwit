## 1. Резюме (TL;DR)

Архитектура **соответствует задаче и правилам AGENTS.md**: статический одно-страничный лендинг (HTML5 + CSS3 + Vanilla JS, без бэкенда), mobile-first, семантическая вёрстка, деплой на Vercel — правильный минимальный выбор без over-engineering. - Ряд улучшений по производительности, доступности и SEO — P2.

## 3. Оценка архитектуры

### Что сделано правильно

1. **Стек** — чистый статический HTML/CSS/JS. Для одностраничного лендинга услуг без форм это оптимально: ноль рантайма, ноль сборки, мгновенный деплой на Vercel. Соответствует AGENTS.md (HTML5/CSS3/Vanilla JS, без лишнего).
2. **Структура и нейминг** — плоско, lowercase-дефисы (`landing-eduardwit`), типы файлов логичны. Соответствует правилам нейминга AGENTS.md.
3. **Семантика HTML** — `header/nav/main/section/article/footer`, единственный `h1`, `aria-label` на навигации и бургере, `aria-expanded`/`aria-controls` на кнопке меню, `rel="noopener"` на внешних ссылках, `lang="ru"`.
4. **SEO-база** — `title`, `description`, OG-заголовок/описание, `theme-color`.
5. **Производительность по умолчанию** — `preconnect` для шрифтов, `display=swap`, без тяжёлых библиотек, без изображений в критическом пути.
6. **Контент-структура** — hero → услуги → кейсы → контакты: классическая воронка для ЦА «владельцы бизнеса»; CTA повторяется в header, hero, кейсах и контактах.

### Проблемы

1. Битые ссылки на ресурсы (`styles.css`, `script.js`) — страница без стилей и без JS.
2. Зависимость видимости контента от JS: класс `.reveal` в разметке (opacity: 0 до появления). При отключённом/упавшем JS весь контент останется невидимым.
3. Заглушки контактов в путях публикации (см. раздел 4, Business).
4. Якорная навигация без учёта sticky-шапки (нет `scroll-margin-top`) — при переходе по якорям заголовки будут заезжать под шапку.
5. Специфика RU-аудитории не учтена: Google Fonts (может быть недоступен/медленный в РФ), нет Яндекc.Метрики, нет JSON-LD для поиска.

## 4. Перспективы

### Business
- **ROI:** лендинг — это машина заявок. Каждый день «в null» без стилей и с заглушками = потерянные лиды.
- **Главный риск (снят 2026-09-30):** контакты-заглушки заменены на реальные (`+7 919 591-01-01`, `admin@eduardwit.ru`, `@EduardWIT_bot`) — путь заявок рабочий, звонки и письма попадут к владельцу.
- Метрики: без аналитики (RU → Яндекс.Метрика) невозможно понять, какой канал (Telegram/телефон/почта) даёт заявки, и нельзя улучшать оффер.
- Telegram — основной канал ЦА: отсутствие `og:image` делает превью ссылок пустым в переписке, что снижает кликабельность (для B2B-чатов критично).

### Technical
- Ресурсы, на которые ссылается HTML, отсутствуют — сайт де-факто «сломан» до создания CSS/JS. Очередность исправления: CSS/JS → контакты → мета → инфраструктура Vercel.
- `vercel.json` отсутствует: нет security-заголовков (CSP, X-Content-Type-Options, HSTS) и кэш-политики для статики (длинный `Cache-Control` для `styles.css`/`script.js` с хешем или `public, max-age` для неверсионированных файлов — что можно, т.к. файлы меняются вручную).
- Нет файлов индексации: `robots.txt`, `sitemap.xml`, `404.html`, canonical. Для одного лендинга — малый приоритет, но дешёвый и правильный для запуска.
- Шрифты: сторонний CDN (Google Fonts) — единственная внешняя зависимость. При недоступности CDN фолбэк должен быть системным; `display=swap` уже защищает от блокировки рендера.

### User
- **Доступность:** `.reveal`-анимации опасны для пользователей с `prefers-reduced-motion` и для заскринованных вёрсток (если JS не выполнился). Нужен CSS-only fallback и уважение к `prefers-reduced-motion`.
- Контакты как `tel:`/`mailto:` — хорошо для мобильных, но без видимого `+7 …` в обычном тексте? Есть — кнопка с номером. ОК.
- Финальный контент-контраст (WCAG AA) проверить после появления стилей; особенно тёмный блок контактов — по правилу Эдуарда (явные `color`/`background` у текста и кнопок в тёмных блоках).

### Risk
| Риск | Вероятность | Влияние | Mitigation |
|---|---|---|---|
| Публикация с заглушками | высокая (без чеклиста) | критическое | Чеклист раздела 8 перед `vercel --prod` |
| JS-off / медленный JS → невидимый контент | средняя | высокое | CSS-only reveal, класс `no-js`, `prefers-reduced-motion` |
| Google Fonts недоступен (РФ) | средняя | низкое | системный фолбэк-стек; опция self-host (P2) |
| Рассинхрон контактов в бриф/код | средняя | среднее | держать контакты в одном месте (бриф как источник истины) |

## 6. Улучшения (приоритизировано)

### P1 — до публикации

1. **Favicon** — `favicon.svg` + `apple-touch-icon` (иконка 180×180); сегодня браузер отдаёт 404 на `/favicon.ico`.
2. **`og:image`** — статичная OG-картинка 1200×630 с логотипом/оффером; превью в Telegram/WhatsApp станут кликабельными.
3. **Аналитика** — Яндекс.Метрика (RU-ЦА): счётчик + цель «клик по контакту». Без неё лендинг бизнеса «слепой».
4. **`vercel.json`** — security-заголовки (`X-Content-Type-Options: nosniff`, `Referrer-Policy`, базовая CSP без inline-блокировок, при желании HSTS на прод-домене) + кэш `public, max-age=31536000, immutable` для статики с хешем в имени (или скромный `max-age=86400` для ручных правок).
5. **Fallback для reveal** — `.reveal` должен показывать контент без JS: `html.no-js .reveal { opacity: 1 }` + слушать `prefers-reduced-motion: reduce` → отключать анимации.
6. **Якоря под sticky-шапку** — `scroll-margin-top` на `section[id]`/`[id="top"]`; `scroll-behavior: smooth` только при `prefers-reduced-motion: no-preference`.
7. **Тёмный блок контактов** — явные `color`/`background` для текста, кнопок и фокуса (правило из Trepka-сессий: не полагаться на наследование).
8. **Реальные контакты** — вынести в бриф как источник истины и подставить в разметку.

### P2 — после запуска

9. **Self-host шрифтов** (Manrope/Playfair) — минус зависимость от Google, быстрее в РФ, приватность. Оставить `display=swap` и системный фолбэк.
10. **JSON-LD** (`ProfessionalService`/`Person`) — расширенные сниппеты в поиске.
11. **`robots.txt` + `sitemap.xml` + `404.html`** — корректная индексация и UX битых ссылок.
12. **Контраст и доступность** — прогон Lighthouse (a11y 95+), ручная проверка 320px и 4K, фокус-стили у кнопок/ссылок (`:focus-visible`).
13. **A/B-оффер** — после 2–3 недель Метрики протестировать заголовок hero/CTA (вариант на чистом JS или через цели).

### Намеренно НЕ рекомендую

- Сборку (Vite/SCSS/минификатор) — for 1 страницы это over-engineering, запрещён AGENTS.md; статика + простой CSS быстрее и надёжнее.
- Многостраничность (блог/портфолио отдельно) — расширять только по реальной потребности.
- Формы с бэкендом — контакт через `tel:/mailto:/Telegram` покрывает текущую задачу; серверные формы добавить, когда появится заявка-поток и API (n8n).
